# Installer & Uninstaller Mod Bahasa Indonesia - Dark Souls II: Scholar of the First Sin

Karya: **ShDitz**

Repositori ini khusus menyediakan skrip instalasi otomatis (`install_mod.bat`) dan penghapusan (`uninstall_mod.bat`) untuk **Mod Bahasa Indonesia Dark Souls II: Scholar of the First Sin**.

Berkas paket mod utama diunduh terpisah melalui halaman resmi Nexus Mods.

## Cara Pasang (Install)

1. Unduh berkas mod utama (`DS2Subtitleindo.zip`) dari halaman Nexus Mods.
2. Ekstrak berkas `DS2Subtitleindo.zip` tersebut di komputer Anda. Anda akan mendapatkan folder bernama `DS2Subtitleindo`.
3. Pindahkan folder `DS2Subtitleindo` tersebut ke dalam direktori instalasi game Anda (tempat `DarkSoulsII.exe` berada).
   Contoh lokasi folder game di Steam:
   `C:\Program Files (x86)\Steam\steamapps\common\Dark Souls II Scholar of the First Sin\Game\`
4. Unduh file `install_mod.bat` dan `uninstall_mod.bat` dari repositori GitHub ini.
5. Masukkan file `install_mod.bat` dan `uninstall_mod.bat` tepat di dalam folder `DS2Subtitleindo` yang sudah dipindahkan ke folder Game tadi.
6. Pastikan game Dark Souls II dalam keadaan tertutup.
7. Buka folder `DS2Subtitleindo`, lalu klik ganda pada `install_mod.bat` (jika game berada di Program Files, klik kanan lalu pilih "Run as administrator").
8. Tunggu proses instalasi selesai. File asli game akan otomatis dicadangkan ke folder `original`.
9. Jalankan game, masuk ke menu **Game Options** (Opsi Permainan), lalu pastikan opsi **Subtitle** diatur ke **Aktif**.

## Cara Hapus (Uninstall)

Jika Anda ingin mengembalikan game ke kondisi asli (Bahasa Inggris bawaan):

1. Pastikan game sedang ditutup.
2. Buka folder `DS2Subtitleindo` di dalam folder Game Anda, lalu klik ganda file `uninstall_mod.bat`.
3. Skrip akan otomatis mengembalikan berkas asli dari folder `original` dan membersihkan file mod.

## Hal Penting

- Folder `original` dibuat otomatis oleh installer sebagai cadangan file asli game Anda. Jangan hapus folder `original` ini agar uninstaller bisa mengembalikan game kapan saja.
- Mod ini murni mengubah teks dan tekstur antarmuka tanpa menyentuh file save data maupun statistik permainan.
