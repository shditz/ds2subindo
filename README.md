# Installer & Uninstaller Mod Bahasa Indonesia - Dark Souls II: Scholar of the First Sin

Repositori ini menyediakan file `install_mod.bat` dan `uninstall_mod.bat` untuk memasang serta menghapus Mod Bahasa Indonesia Dark Souls II: Scholar of the First Sin (karya ShDitz) secara otomatis.

File mod utama (folder `menu` dan `SeamlessCoop`) diunduh terpisah melalui halaman Nexus Mods.

## Cara Pasang (Install)

1. Unduh file mod dari Nexus Mods, lalu ekstrak. Anda akan melihat folder `menu` (dan folder `SeamlessCoop` jika menggunakan co-op).
2. Unduh file `install_mod.bat` dan `uninstall_mod.bat` dari repositori ini (tombol hijau Code > Download ZIP, atau unduh file langsung).
3. Letakkan file `install_mod.bat` dan `uninstall_mod.bat` di folder yang sama dengan folder `menu` tersebut.
4. Pastikan game Dark Souls II sedang ditutup.
5. Klik ganda pada `install_mod.bat`. Jika game Anda terpasang di folder Program Files, klik kanan lalu pilih "Run as administrator".
6. Installer akan otomatis mencari letak game Steam Anda, membuat cadangan file asli ke folder `original`, lalu memasang mod.
7. Jalankan game, masuk ke menu Game Options (Opsi Permainan), lalu pastikan opsi **Subtitle** diatur ke **Aktif**.

## Cara Hapus (Uninstall)

Jika Anda ingin mengembalikan game ke kondisi awal (Bahasa Inggris):

1. Pastikan game sedang ditutup.
2. Klik ganda pada `uninstall_mod.bat` di folder yang sama.
3. Uninstaller akan otomatis mengembalikan file asli dari folder `original` dan membersihkan file mod.

## Hal Penting

- Skrip `install_mod.bat` otomatis membuat folder `original` sebagai cadangan file asli game. Jangan hapus folder `original` ini agar uninstaller bisa mengembalikan game Anda kapan saja.
- Mod ini hanya mengubah teks tampilan dan tekstur antarmuka tanpa menyentuh file save data maupun statistik permainan.
