CARA PASANG MOD BAHASA INDONESIA DARK SOULS 2 SOTFS
Karya: ShDitz

1. Pindahkan folder "ds2subindo-main" ke dalam folder instalasi game (tempat DarkSoulsII.exe berada):
   ...\Dark Souls II Scholar of the First Sin\Game\
2. Tutup game Dark Souls 2 jika sedang berjalan.
3. Buka folder "ds2subindo-main", lalu klik ganda pada "install_mod.bat" (atau klik kanan pilih "Run as administrator").
   Installer akan otomatis mencadangkan file asli ke folder "original" dan memasang mod.
4. Buka game, masuk ke Game Options (Opsi Permainan), lalu pastikan opsi Subtitle = AKTIF.

Jika Anda memakai Seamless Co-op, terjemahan menu, item co-op, dan pengumuman pembuka akan otomatis terpasang.

CARA HAPUS MOD (KEMBALIKAN KE BAHASA INGGRIS):
1. Tutup game jika sedang berjalan.
2. Buka folder "ds2subindo-main" lalu klik ganda pada "uninstall_mod.bat".
   File asli game akan otomatis dikembalikan ke kondisi semula.
